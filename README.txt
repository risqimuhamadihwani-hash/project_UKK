SISTEM INFORMASI PENJUALAN TOKO - HALAMAN LOGIN
================================================

Teknologi:
- PHP Native
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap 5

CARA MENJALANKAN:
1. Install XAMPP.
2. Salin folder "sistem-penjualan-login" ke:
   C:/xampp/htdocs/
3. Jalankan Apache dan MySQL dari XAMPP.
4. Buka phpMyAdmin.
5. Import file database.sql.
6. Buka browser:
   http://localhost/sistem-penjualan-login/login.php
